SS plan — Prototype V3 : dessinateur de façade

Fonctions :
- Interface français / allemand / italien
- Dimensions de façade, choix de système, largeur de travée et hauteur de niveau
- Ajout de fenêtres, portes, balcons et obstacles
- Schéma généré automatiquement avec structure de travées et niveaux
- Estimation indicative de composants génériques
- Sauvegarde locale et impression / export PDF via le navigateur

Tester :
1. Décompresser le ZIP.
2. Ouvrir index.html dans un navigateur récent.
3. Modifier les dimensions, choisir un élément puis « Ajouter à la façade ».
4. Utiliser « PDF / Imprimer » pour imprimer ou enregistrer en PDF.

Limites importantes :
Prototype de démonstration uniquement. Les quantités sont des estimations géométriques
génériques, pas des nomenclatures fabricant. Pas de calcul de stabilité, charges,
vent, ancrages, accès ou conformité. Ce dessin n'est pas un plan de montage.
Une personne compétente doit valider chaque étude selon les exigences suisses,
les règles SUVA applicables et la documentation du fabricant.

Pas encore de comptes, serveur, synchronisation cloud, paiements ni catalogue officiel.
Pour installer comme PWA, héberger les fichiers sur HTTPS puis « Ajouter à l'écran d'accueil ».
